Indentation#

Python uses whitespaces to define code blocks. A single whitespaces at the beginning of a line is consider a simple indent. A code block that is indented with the same number of leading whitespaces or tabs should be run together.

In other words: the indentation is part of the syntax in python and one of the major distinctions compared to other programming languages like, e.g. Matlab.

Usually in Python we use four whitespaces for indentation of code blocks (simply hitting the tabkey does the trick). This is defined in the PEP8 Style Guide under whitespace “ethics”.

Let’s see what that means:

days_til_christmas = 51
current_weekday = 'Saturday'

Each set of these statements is called a block, meaning that the lines/variable assignments will be run together. We will see examples of how blocks are important later on.

What happens when we introduce a “wrong” indentation?

days_til_christmas = 51
  current_day = 'Saturday'

    days_til_christmas = 51
        current_day = 'Saturday'

One thing you should remember here: A wrong indentation raises an IndentationError.

Indentation will become important in the following …

Conditional statements: if, elif, else#

Conditional statements are a bit like decision making: if it rains outside, then bring an umbrella; if the sun shines outside, then use sun lotion before leaving the house; etc. In programming, we often have to make the execution of a code block dependent on certain conditions. This is what conditional statementsallow us to do.

The python syntax for conditional execution of code uses the keywords if, elif (this means something like: else if), and else:




learnbyexample: Python-elif-Statement-Syntax

Here is another way of visualizing this:

alphacodingskills: Python-if-elif-else

To quickly demonstrate, we’ll define two False statements and see how if, elif and else deal with booleans:

statement1 = False
statement2 = False

if statement1 == True:
    print("statement1 is True")
    
elif statement2:
    print("statement2 is True")
    
else:
    print("statement1 and statement2 are False")

Note that in the second conditional (elif ...) we are using highly efficient syntax! Just like in the first conditional test, we are asking if the variablee statement2has the value True. The True boolean is silent in our conditionals.

Also note that python syntax is efficient in another sense here: While in everyday decision making, we say if X then Y, python replaces the then by the colon : combined with indentation!

So remember: Program blocks are defined by their indentation level.

In Python, the extent of a code block is defined by the indentation level (usually a tab or four white spaces). This means that we have to be careful to indent our code correctly, or else we will get syntax errors, as we have seen above.


https://docs.python.org/3/tutorial/errors.html#syntax-errors](https://docs.python.org/3/tutorial/errors.html#syntax-errors

Examples:

# Good indentation
statement1 = statement2 = True

if statement1:
    if statement2:
        print("Both statement1 and statement2 are True.")

To translate this a bit: IF statement1 is True THEN execute a new code block (indicated as such by indentation) and test IF statement2 is True. Only IF statement2 is also True, THEN execute the following code block (indicated as such again by further indentation) and print the output.

By the way: This can be called a nested if statement`.

# Bad indentation! This would lead to an error
if statement1:
    if statement2:
    print("both statement1 and statement2 are True")  # this line is not properly indented

Now what does this error tell us?

statement1 = False 

if statement1:
    print("printed if statement1 is True")
    
    print("still inside the if block")

Oh no! Where is our output? I think you know why nothing was printed, right?

Well, let’s try again. This time let’s be explicit in what we’re trying to conditon on by using the is keyword and the == comparison operator (remember those?)

statement1 = False # still False

if statement1 == True:
    print("printed if statement1 is True")
    
    print("still inside the if block")
    
elif statement1 is False:
    print("printed if statement1 is False")
    
    print("still inside the elif block")

(Note that now you know three different ways of testing Booleans!)


OK: `If` `conditionals` care about `indentation`. What happens if we're not on the same `indentation level`?
statement1 = True
statement1 = not False # so True

if statement1:
    print("printed if statement1 is True")
    
print("now outside the if block")

So what happens here? Because the second print command is not at the same indentation level, it is not part of the code block that depends upon the if statement. It is at the same indentation level as the if-statement, so it is executed independent of the if-statement.

Using the or & and logic from the last session, we can even combine statements:

print("Statement2 was:", statement2, "right?")
print('So:')

if statement1 and statement2:
    print("printed if statement1 and statement2 are True")
elif statement1 or statement2:
    print("printed if either statement1 or statement2 is True")
else:
    print("printed if no statement is True")

Loops#

In python, loops can be programmed in a number of different ways. The most common is the for loop, which is used together with iterable objects, such as lists. In other words: we can use a for loop to iterate over a list and execute a code block for every item in the list. That makes sense, doesn’t it?

The basic syntax is:


https://www.learnbyexample.org/wp-content/uploads/python/Python-for-Loop-Syntax.png
via GIPHY
for i in [1,2,3]:
    print(i)

But why that i? Honestly, that is mostly a mixture of laziness and force of habbit. Technically you could give your variable that you iterated over any name that is not a python keyword or function name and in general you should be as specific as possible, whenever possible for everyone’s sake.


via Reddit

So let’s try that again:

for num_in_list in [1,2,3]:
    print(num_in_list)

Remember that our iterable_variable will be continously updated. That means in every iteration of the loop, our variable will have a new value, in the present case: first 1, then 2, then 3. So if we call num_in_list again (i.e., after the loop was run), we’ll get the last assigned value, i.e. the last item in our list.

num_in_list

So our for loop iterates over the elements of the supplied list and executes the contained code block once for each element. Any kind of list can be used in the for loop.

It’s common to employ the range() function, which we’ve met in the previous session, to define how many times a loop should repeat. For example:

for i in range(4): # remember that by default range start at 0
    print(i)

#  to demonstrate that you could also create a list using range by
list_range = list(range(4))
print(list_range)

print("And now we print it out by looping over the list:")
# results in the same as before
for i in list_range:
    print(i)

print(i)

Note: range(4) does not include 4! Try to remember the aspects of indexing and slicing we addressed during the session on strings and lists.

for x in range(-3,3):
    print(x)

Again, you can use any kind of list, so let’s try a list of strings:

for word in ["scientific", "computing", "with", "python"]:
    print(word)

and the variable word again contains the last item of the list we used, i.e. the variable assumes the value of the last loop iteration

word

To iterate over key-value pairs of a dictionary we need to change up our syntax a bit. So we include 2 variables when defining our for loop, like so:

# define a dictionary
params = {
    'parameter1': 'A',
    'parameter2': 'B',
    'parameter3': 'C',
    'parameter4': 'D'
}
print(params)

Remember that we can directy access a list of the keys, e.g.:

print(params.keys())

We can also use this list of keys to iterate over the key-value pairs of a dictionary.

for key in params.keys():
    print(key)

for value in params.values():
    print(value)

Or, what you willl usually see in python: (Note: If this does not become clear directly, please take a minute to think about it!)

for key, value in params.items():
    print(key + " = " + str(value))

Note that with this syntax (i.e., for x, y in ...) the for loop increments both variables xand y on every interation of the loop!

Sometimes it is also useful to have access not to the values themselves but to the indices of the values when iterating over a list. We can use the enumerate function for this:

# note that the convention is to call our index varivale `idx`
for idx, x in enumerate(range(-3,3)):
    print('loop number = ' + str(idx))
    print(x)

break, continue and pass#

We hope that it became clear how loops work!

But at times it is necessary to further control how a loop behaves. We’ll therefore introduce a few control statements.

To control the flow of a certain loop we’ll use break, continue and pass.

To illustrate this let’s first create another list

rangelist = list(range(10))
print(list(rangelist))

Now if we want our loop to stop running once a condition is met we need our old friends the if and else conditional statements. We’ll evaluate if a certain number is contained in our list and break the loop once a [4, 5, 7, 9] is found.

for number in rangelist:
    # First, let's check if number is one of
    # the numbers in our list of critical values:
    if number in [4, 5, 7, 9]:
        # "Break" terminates a for loop without
        # executing the "else" clause.
        print(number)
        print('number ' + str(number) + ' encountered. Loop breaks here!')
        break
    else:
        # If the current number is not in our critical 
        # list, then execute the following code:
        print(number)
        print('continued')
        # "Continue" starts the next iteration
        # of the loop. It's rather useless here,
        # as it's the last statement of the loop
        # but it can be useful ...
        continue
else:
    # The "else" clause is optional and is
    # executed only if the loop didn't "break".
    # Note that all previous examples of for loops
    # did not have an else satement and worked fine.
    pass # Do nothing

So breaking the loop indeed means that it is stopped and not continued with the next item of the iterable variable!

Now, let’s see what continue and pass can actually be good for. Continue implies that we don’t want our for loop to end, but rather to skip the rest of code block for the current iteration. So:

for number in rangelist:
    if number in [4, 5, 6]:
        print('number ' + str(number) + " encountered. We're supposed to break, right?")
        print("oh no the loop can't hear us it has a continue statment in it!")
        continue  # stop here, continue with next loop

        print('so this break statement will never be read?!')
        break

    elif number in [8, 9]:
        print(str(number))
        print("break? break!")
        break
        
        print('so this continue statement will never be reached?!')
        continue        

    else:
        print('else number = ' + str(number))

So continue can for example be used to ‘shortcut’ a loop and not execute its code for certain values.

What about pass then? We’ll use it to tell our loop to do nothing if a certain condition is met. Exciting, i know!

for number in rangelist:
    if number in [4, 5, 7, 9]:
        print('If statements: number ' + str(number) + ' encountered!')
    elif number in [2, 3, 6]:
        pass
        print('elif_statement: number ' + str(number) + ' encountered!' + ' ...continuing...')
        pass
    else:
        print('else_statement: number ' + str(number) + ' encountered!' + ' ...continuing...')
        continue

This is mostly used as a placeholder for code you haven’t written yet and allows us to avoid the kind of syntax errors you see in the next example

for number in rangelist:
    if number in [4, 5, 7, 9]:
        print('If statements: number ' + str(number) + ' encountered!')
    elif number in [2, 3, 6]:
        # indented code-block expected, this will lead to an syntax error

    else:
        print('else_statement: number ' + str(number) + ' encountered!' + ' ...continuing...')
        continue

LAST BUT NOT LEAST: List comprehensions: Creating lists using for loops:

Now you might encounter some strange looking loops when looking for code online. To keep code sparse and simple looking, programmers may sometimes opt to use a single line instead of an indented block for their loops by using list comprehensions.

A convenient and compact way to initialize lists would then look like this:


https://www.learnbyexample.org/wp-content/uploads/python/Python-List-Comprehension-Syntax.png

How would you explains this code snippet in natural language?
https://4.bp.blogspot.com/-uRPZqKbIGwQ/XRtgWhC6qqI/AAAAAAAAH0w/--oGnwKsnpo00GwQgH2gV3RPwHwK8uONgCLcBGAs/s1600/comprehension.PNG

We’ll use it to square every number x in a list containing the numbers 0 - 4 and add those to a new list called list_x_squared:

list_x_squared = [x**2 for x in range(0,5)]

print(list_x_squared)

You can also use an if statement in your list comprehension. But be careful with the ordering. A single if can be after the for loop. However, if and else together have to be in front. Lets see some examples.

# if our x is greater than 2, run the list comprehension
list_2 = [x**2 for x in range(0,5) if x > 2]
print(list_2)

list_3 = [x**2 for x in range(0,5) if x > 2 else x]
print(list_3)

Now lets put the if-else statement before the for loop

list_3 = [x**2 if x > 2 else x for x in range(0,5)]
print(list_3)

Don’t be discouraged if that looks confusing, you’ll get the hang of it once you actually start working or fiddling with list comprehensions. Further, it is always fine to use the explicit loop structure, we’ve learned before!

while loops:#

Sometimes we do not have a certain iterable that we want or can use for our loops. Enter the while loop.

A while loop is used when you want to perform a task indefinitely, until a particular condition is met. It is s a condition-controlled loop.

https://www.learnbyexample.org/wp-content/uploads/python/Python-while-Loop-Syntax.png

Or a different way to visualize the while loop:

https://media.geeksforgeeks.org/wp-content/uploads/20191101170515/while-loop.jpg

If we for example want to print all number below 5, we simply do:

i = 0

while i < 5:
    print(i)
    
    i = i + 1
    
print("done")

Note that the print "done" statement is not part of the while loop body (i.e., of the code block executed during the while loop) because of the difference in the indentation. Note also that - unlike in the syntax image above, we are exiting the while loop without an else: statement. In many cases, this is perfectly fine to do.

But what is the i = i + 1 code block? Check back in the first python lesson for a qucik refresher, if necessary. (You might even remember that there was a different notation to achieve the same!?!)

For our next trick, we’ll be a bit more explicit in our variable naming:

counter = 0

while counter < 5:
    print(counter)
    
    counter = counter + 1
    
print("done")

So the i = i + 1 updates our conditional variable on each iteration by 1 + it’s previous value. Or put differently: It is incremented by 1 during each iteration of the while loop.

If you would forget the i = i+1 expression and our conditional variable would never be updated, we’d be stuck in our while loop forever, as the condition is never set to not True . Therefore while loops can be dangerous to use, if you’re not careful.

# If you run this cell you will need to stop the kernel, as it is an infinite loop
# If you decide to do so, maybe first find out how to stop the kernel, right???
# i = 0
# while i < 5:
#     print(i)

As you have seen above, you can also include an else statement after your while loop, to include a codeblock that should be executed once the condition is False

counter = 0

while counter < 3:
    print("Inside loop")
    counter = counter + 1
else:
    print("Inside else")

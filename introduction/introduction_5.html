Introductory Session V#

Dear all, In the fifth session we’ll continue to explore the basic building blocks of python, this and the next session will contain exhaustive content aiming to provide you with a somewhat detailed understanding of central python aspects. The aim is to get a good set of basic experience to then advance into more practical aspects, specifically evaluating how these things can be utilized within experiments to collect data and their subsequent analysis. To nevertheless get some hands-on experience on the way, there will be some exercises at the beginning and throughout the session. Additionally, the homework assignment will be made in a way that showcases some tasks that you might most likely encounter in real-life (ok, real life as a psychology researcher …) so that you get more practice in conducting them through python.

Introduction to Python - Part III#

This session, we’ll build upon the things learn last week and broader our capabilities in python, focusing on two important concepts: indentation of programming code and conrol flow.

Objectives 📍#

  • learn about indentation (some form of code structuring)

  • control how our code is executed

    • Conditionals (if - else statements)

    • Iteration (e.g., for-loops, while statements…)

    • Have a great time (as always …)

Materials 📓#

Please see the rendered version of the jupyter notebook Introductory Session V - Introduction to Python Part III in the ToC on the left.

You can also download the executable notebook itself from the ‘github repository’ of the course, here (you find it under the subfolder ‘lecture/introduction’: https://tinyurl.com/pfp25github

Remember: You actually have multiple options to work with the downloaded ‘jupyter notebook’. You can start a ‘jupyter server’ in your web browser like we did last session. However, you can also open the jupyter notebook in ‘PyCharm’ or in any other interactive editor that you may happen to be using anyway (like ‘VSCode’). This is up to you.

Homework Assignment: 🖥️✍🏽📖#

Your fifth homework assignment will entail working through a few tasks covering the contents discussed in this session within a jupyter notebook. You can download it here. In order to open it, put the homework assignment notebook into the folder you stored the course materials, start a jupyter notebook as during the sessions, navigate to the homework assignment notebook, open it and have fun! NB: There are again some optional parts in the assignment. Also remember that you can work on your homework in groups, as long as you indicate at the top of the homework notebook, with whom you’ve worked together.

Remember: The assignment notebook itself contains info on how to name the finished notebook and where to send it.

Deadline: Tuesday 02/12/2025, 11:59 PM EST

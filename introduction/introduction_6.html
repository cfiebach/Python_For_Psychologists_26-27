Introductory Session VI#

Within the sixth session we’ll finish exploring some basic building blocks of python. The aim is to get a good set of basic experience to then advance into more practical aspects, specifically evaluating how these things can be utilized for running experiments in python to collect data and, subsequently, exploring how python can be used to analyze data.

Introduction to Python - IV#

This session, we’ll build upon the things learned in the last weeks and see how repeated tasks in python can be efficiently combined as `functions that can be called whenever they are needed.

Objectives 📍#
